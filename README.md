# Airline-Analytics
Airline Analytics – SQL, Python &amp; Power BI = Analyzed airline flight, booking, and customer satisfaction data using SQL, Python, Pandas, Matplotlib, and Power BI. Developed an interactive dashboard to track flight performance, cancellations, popular routes, monthly trends, and customer satisfaction, helping identify useful business insights.
